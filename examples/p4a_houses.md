## ——— 1宫（自我）· 摩羯座 ———

### 【状况概述】

你这个人给人的第一印象是"稳"——摩羯座上升带来的气质是踏实、自律、有边界感，外表不张扬，但内里有一种天然的结构感。你走进一个房间，不会是最吵的那个，但往往是最能承重的那个。

1宫的管家是土星（Core-Driver，1宫主），但它跑去了7宫（合伙/婚姻）。这叫"管家不在家"——意味着你对自我的建立有一部分是通过关系完成的：你在跟人合作、跟人深度连接的过程中，才会越来越清楚自己是谁，想要什么。单打独斗时反而容易迷失方向。土星逆行，这种通过关系认识自己的过程还带着一层"反复审视"的底色——你会在关系里反复确认自己的位置和价值，慢，但最终会建立起非常扎实的自我认知。

1宫里有金星（Yogakaraka，5/10宫主）坐在这里。这是这张盘最重要的配置之一：你这个人的气质和事业方向是高度融合的——你展现自我的方式本身就是你的事业。外人看到的你，就是你在做事业时最真实的样子。金星在1宫还带来了一种美感和温度：你不是那种刻板的职业面具，做事情会带有自己的风格和审美。

**相位**：Ketu相位1宫（5th相位，来自9宫），带来灵性色彩；Saturn从7宫相位1宫（7th互望）。土星远程管理自己的家——有一种"远程监控"的味道，你的自我建立有延迟，但控制质量很高。

| 维度 | 结果 |
|------|------|
| 管家 | Saturn(Core-Driver)→7宫，逆行，Dig Bala |
| 住客 | Venus(Yogakaraka)，气质与事业融为一体 |
| 相位 | Saturn(7宫互望)、Ketu(9宫5th) |
| 宫位SAV | 1宫(Cp)=29，平稳 |

### 【事件关联】

Moon大运（2006-2016）期间，1宫没有直接被激活，但那个正面期的童年给你的自我发展提供了稳定的情感土壤；Mars大运（2016-2023，正面期）是你自我形象快速建立的阶段——火星在4宫入庙，4宫代表基础教育和家庭环境，那7年是你建立"我是谁"核心认知的关键期。（推导：Mars=L4/L11，入庙4宫，正面4/0→正面期，家庭和基础教育资源充足）

## ——— 2宫（财富/语言/家族）· 水瓶座 ———

### 【状况概述】

2宫的管家也是土星（同时管1宫和2宫）。土星去了7宫，意味着你的财富积累和家庭财务同样有"管家远程"的特点——收入不是自动进账的，需要你主动去维护，去关注，去把7宫的合伙能量转化成2宫的财务成果。

水瓶座2宫给你的财富观带来一种"非传统"的色彩——你赚钱的方式不会是最保守的那种，可能涉及新技术、集体性项目、或者有某种社会价值的事业方向。你对钱的态度是务实但不守旧的，不会为了稳定而放弃可能性。

2宫空宫（无行星居住），Jupiter从10宫相位2宫（Jupiter的7th相位覆盖2宫）。木星相位财富宫，带来扩展性：在Jupiter小运期间（当前Rahu-Jupiter 2025-2028），财富方向会有一定的开阔感，可能有收入增长或财务视野的扩展。但要记得木星管12宫（欺骗性风险），扩展同时要防止无形耗散。

| 维度 | 结果 |
|------|------|
| 管家 | Saturn(Core-Driver+L2)→7宫，逆行管理 |
| 住客 | 空宫 |
| 相位 | Jupiter(10宫7th相位) |
| 宫位SAV | 2宫(Aq)=28，平稳 |

## ——— 3宫（行动/传播/兄弟/技能）· 双鱼座 ———

### 【状况概述】

3宫是Rahu的住所。Rahu坐在双鱼3宫，这个位置很有意思：双鱼本身是一个流动、梦幻、感知力强的星座，Rahu在这里给3宫（行动/传播/技能）注入了一种"边界模糊的探索欲"——你的行动力不是直线型的冲刺，而是像水一样渗透，会进入各种意想不到的领域，用非常规的方式去发现机会。

3宫的管家是木星（3宫主），去了10宫（事业宫）。管家在外跑事业——这意味着你的技能和行动力，最终出口是在事业上。你不会为了动而动，你的行动有明确的事业方向导向。

**3宫(Pi)SAV=33，超过32，触发极端标注**：3宫资源溢出。Rahu在一个资源超充裕的3宫，行动和传播方向有很强的天然资源支撑。这是这张盘里少数资源超载的宫位——你在需要"行动力"和"传播自己想法"的事情上，有比别人更充足的弹药。

| 维度 | 结果 |
|------|------|
| 管家 | Jupiter(L3)→10宫，技能出口指向事业 |
| 住客 | **Rahu**，探索型、边界模糊 |
| 相位 | Ketu(9宫7th互望)、Saturn(7宫3rd相位) |
| 宫位SAV | **3宫(Pi)=33，溢出**，行动力资源极充裕 |

## ——— 4宫（家庭/学习/不动产）· 白羊座 ———

### 【状况概述】

4宫是这张盘里最强的宫位之一，没有悬念。火星入庙坐在白羊4宫，Ruchaka Yoga在此激活——这叫"管家亲自坐守"，4宫的管家（Mars是L4）待在自己的家里，入庙，状态满分。

4宫代表：家庭基础、早年教育、情感安全感、不动产、母亲、内心的根。火星在这里意味着你的家庭底色是充满能量和活力的，家给你的是"力量"而不是"避风港"——是那种推着你往前走的家庭氛围，而不是让你缩着待着的舒适圈。

从D4不动产盘交叉：金星和土星都在D4的4宫（Capricorn）。这三重信号叠加——D1/D4 4宫都有很强的配置，意味着不动产和物质基础方面有扎实的先天条件。节奏会慢（土星主导），但会稳稳地在某个时段（Saturn大运附近，或Venus大运）实现。

Jupiter和Saturn都相位4宫（Jupiter从10宫7th相位，Saturn从7宫3rd相位）——两颗重量级行星都在看4宫，带来额外的保护和资源支撑。

| 维度 | 结果 |
|------|------|
| 管家 | **Mars(L4)→4宫自管，入庙，Ruchaka Yoga** |
| 住客 | Mars，最强状态 |
| 相位 | Jupiter(7th)、Saturn(3rd) |
| 分盘 | D4中Venus+Saturn坐D4的4宫，不动产基础扎实 |
| 宫位SAV | 4宫(Ar)=28，平稳 |

### 【事件关联】

Mars大运（2016-2023，正面4/0→正面期）：4宫主当值，且在自管宫入庙。这7年是4宫事务的高光期——家庭关系稳定、学习基础打牢（初高中阶段）、内心安全感充足。格局激活验证：Ruchaka Yoga在Mars大运期间高质量激活（D9支撑90%兑现率）。（推导：Mars=P7入庙，P5=4宫自管，P9=126%，正面4/0→正面期）

## ——— 5宫（创造力/恋爱/投资/子女）· 金牛座 ———

### 【状况概述】

5宫有月亮入旺，这是全盘最大的亮点之一。月亮管7宫（配偶/合伙），它跑进了5宫（恋爱/创造），入旺待着——意思是：你的感情力量是天然充足的，而且感情和创造力是深度绑定的。你在恋爱中会有很强的情感感受力，对方很容易感受到你的温度。你的创造力也带有情感驱动的底色——你做出来的东西是有感情的，不是冷冰冰的逻辑产物。

5宫的管家是金星（L5，Yogakaraka），去了1宫（自我宫）。管家在外但在吉宫，意味着创造力和恋爱资源会通过你的自我表达来激活——你越是真实地做自己，这个宫位的能量就越流动。

5宫被多颗星相位：Sun/Mercury从11宫（7th相位），Ketu从9宫（9th相位）。Sun和Mercury相位5宫，带来深度思维和信息处理能力注入创造宫——你的创造力有智识性，不只是感性，还带有分析和表达的维度。Ketu相位5宫，带来一种对创造物"不执著于结果"的态度。

从D5创造力盘：太阳坐D5 Lagna（上升），影响力和创造力内核强。

## ——— 6宫（竞争/疾病/债务/服务）· 双子座 ———

### 【状况概述】

6宫是空宫（无行星居住），管家是水星（L6），去了11宫。管家跑去收入宫了——这个配置叫"竞争者的管家在赚钱"，人话是：你在竞争和服务领域的能量最终会转化成收入，6宫事务（困难和竞争）不是纯粹的阻力，是你变现的通道之一。

但水星是敌方位（Scorpio），管家在外且状态有内耗，6宫的事务（健康、竞争、服务）需要你比别人多花一点功夫去维护，不会是最省力的领域。

好消息是：Jupiter从10宫相位6宫（7th相位）。木星看6宫，带来保护和扩展——在竞争和服务方向上，木星给你提供了一定的缓冲和机会。这不会让6宫变成福地，但会让你在竞争里偶尔有"意外转机"的感觉。

6宫(Ge)SAV=26，平稳偏低边缘，不触发极端标注，但值得知道竞争环境资源中等。

| 维度 | 结果 |
|------|------|
| 管家 | Mercury(L6,GK)→11宫，竞争能量转化为收入 |
| 住客 | 空宫 |
| 相位 | Jupiter(10宫7th相位) |
| 宫位SAV | 6宫(Ge)=26，中等 |
