# 宫位诊断（二）：7-12宫

---

## ——— 7宫（婚姻/合伙/合约）· 巨蟹座 ———

### 【状况概述】

7宫是这张盘里最值得深聊的宫位。

先说好消息：7宫的管家月亮入旺（在5宫），7宫的"硬件"天然很好——月亮掌管婚姻，入旺就是说这颗星处于最强状态，意味着你在感情和合伙方向有真实的吸引力和连接能力。

但7宫本身有一个需要注意的居住者：土星逆行坐在这里。1宫的管家（Core-Driver）跑到7宫，逆行，坐在巨蟹（它最不舒服的星座之一——土星和月亮是互相制约的，土星在巨蟹是"客居凶境"）。这带来的体感是：你在婚姻和长期合伙关系里，往往会经历一个"反复审视和延迟"的过程。不是感情不好，而是建立信任和深度连接需要时间，你不会轻易对一段关系完全放开——土星要先做质检，确认过才会真正投入。这是慢热型的感情模式。

土星逆行在7宫还有一个深层含义：你在关系里会"回头看"——可能反复思考过去的关系，或者在新关系中带着对旧经历的复盘态度进入。这不是坏事，但如果不加以觉察，可能会变成"用旧标准审判新关系"的障碍。

**UL（Upapada Lagna）在8宫（Leo）**：婚姻指示点落在变故宫，这意味着婚姻在某种程度上是一种深度转化的触发点——你的婚姻不会是平淡无波的，会有某种深度的改变在里面。不是坏事，但婚姻会让你经历一种"脱胎换骨"式的转变。

**相位**：Mars从4宫（7th相位）、Venus从1宫（7th互望）、Rahu从3宫（7th相位）都在看7宫。三颗星相位婚姻宫——这很罕见，意味着7宫的事务受到多方关注和影响。火星带来竞争和热度，金星带来美感和吸引力，Rahu带来非传统性和变数。

| 维度 | 结果 |
|------|------|
| 管家 | Moon(L7)→5宫，入旺，婚姻品质天然好 |
| 住客 | **Saturn(逆行)**，审视型、慢热、建设扎实 |
| 相位 | Mars(4th→7th)、Venus(1宫7th)、Rahu(3宫7th) |
| 特殊 | UL在8宫(Leo)，婚姻带来深度转化 |
| 宫位SAV | 7宫(Cn)=28，平稳 |

### 【事件关联】

Moon大运（2006-2016，正面4/0→正面期）：7宫主当值、入旺，这段时间7宫事务（早期的人际合作模式、父母关系、对"合伙"的第一印象）整体是正向的。（推导：Moon=L7，P7入旺，P5=5宫吉路，正面4/0→正面期）

Saturn大运（2057-2076，正面4/0→正面期）：7宫住客当值，而且那是正面期——这意味着土星在7宫积累了一辈子的能量，到它大运才会全面释放。这是婚姻最稳定、合伙关系最成熟的阶段。

## ——— 8宫（变故/深度转化/遗产/研究）· 狮子座 ———

### 【状况概述】

8宫空宫，管家太阳（L8）去了11宫（收入宫）。清理者的管家跑去收入宫——深度转化和危机处理的能量被引导到了收入方向。这是8宫资源"变现"的配置：你处理复杂问题、做深度研究的能力，会成为收入来源之一。

8宫(Le)SAV=28，平稳，没有极端信号。8宫无行星居住，意味着这个领域不会有特别剧烈的直接冲击——转化会发生，但通过太阳管的方式（渐进的、有结构的），不是突然的崩塌。

没有行星相位8宫（从相位表看，8宫无任何行星投射）——这宫相当"清净"，既没有额外的压力，也没有额外的激活。

| 住客 | 空宫 |
| 相位 | 无 |

## ——— 9宫（运势/信仰/父亲/高等教育）· 处女座 ———

### 【状况概述】

9宫有Ketu坐在这里。Ketu在运势宫，带来一种对"运气"和"信仰"的出世感——你不太依赖命运，也不容易被单一的信仰框架束缚。你对"为什么活着"这类问题有自己独立的思考，但这个思考不是焦虑型的，而是带有某种平静的探寻。

9宫的管家是水星（L9），去了11宫（收入宫）。运势管家在收入宫——这意味着你的运势发展和收入积累有关联：越有钱不一定运越好，但你的人生走向往往会通过财务和社交的扩展来体现。

**9宫(Vi)SAV=32，接近溢出边缘**（32刚好是平稳-溢出的分界），不触发极端标注，但值得关注——9宫的天然资源相当充裕，这是一个底子好的运势宫。

Saturn从7宫相位9宫（Saturn的3rd相位：7+3-1=9）；Rahu从3宫相位9宫（Rahu的7th相位：3+7-1=9）——土星给运势方向带来纪律和延迟，Rahu给运势带来放大和探索的变数。

| 维度 | 结果 |
|------|------|
| 管家 | Mercury(L9,盟友)→11宫，运势能量流向收入 |
| 住客 | Ketu，出世型，不依赖传统运气框架 |
| 相位 | Saturn(7宫3rd)、Rahu(3宫7th) |
| 宫位SAV | 9宫(Vi)=32，接近溢出 |

## ——— 10宫（事业/地位/权威）· 天秤座 ———

### 【状况概述】

10宫有Jupiter坐在这里，是全盘力量最强的行星（Shadbala 125%，全盘第1）。但这颗星是[欺骗性风险]的3/12宫主——有一种"能量充足但方向带毒"的味道。木星在事业宫的存在感很强，给你的事业带来扩展感和视野，但它管的12宫（损耗）在背后提醒：这种扩展有代价，不要过度投入以至于耗散自身。

10宫的管家是金星（L10，Yogakaraka），去了1宫（自我宫）——管家在自我宫，意味着你的事业和你这个人是一体的：你本人就是事业的核心品牌。这也意味着当你觉得"自我"不清晰的时候，事业方向也会模糊；反过来，当你越来越清楚自己是谁，事业路径也会越来越清晰。

**AL（Arudha Lagna）在10宫（天秤座）**：Arudha Lagna代表外界眼中的你，它落在10宫——世人对你的印象和定义，是通过你的事业来建立的。你的社会形象就是你的职业形象，两者高度重合。这是一种"以作品为名片"的存在方式。

Mars从4宫相位10宫（Mars的7th相位覆盖10宫）——火星看着事业宫，给你的事业注入执行力和竞争力：你在事业上不缺动力，遇到需要行动的时候会有天然的冲劲。

| 维度 | 结果 |
|------|------|
| 管家 | **Venus(L10,Yogakaraka)→1宫，事业与自我合一** |
| 住客 | Jupiter(L3/L12,最强但[欺骗性风险]) |
| 相位 | Mars(4宫7th相位) |
| 特殊 | **AL=10宫**，社会形象由事业定义 |
| 分盘 | D10 Lagna=金牛，Venus底色，事业需美感和价值感 |
| 宫位SAV | 10宫(Li)=29，平稳 |

### 【事件关联】

Jupiter大运（2041-2057，混合2/1→混合期）：10宫住客Jupiter当值。这是事业扩张的窗口，Jupiter的力量（全盘第1）会在事业宫充分释放，但混合期意味着同时要应对12宫的耗散压力——扩张有代价，需要有意识地控制损耗。（推导：Jupiter=P7中性，P5=10宫吉路，P9=125%，P1[欺骗性风险]→正面2条负面1条→混合期）

## ——— 11宫（收入/社交/朋友圈/愿望实现）· 天蝎座 ———

### 【状况概述】

11宫是这张盘里最"拥挤"的宫位——Sun（L8，8宫主）和Mercury（L6/L9，6/9宫主）同住天蝎11宫。两颗管功能凶宫的行星待在收入宫，这叫做"深度和复杂性驱动收入"——你的收入来源往往不是最简单直接的，而是有一定深度和复杂性：可能来自研究、信息处理、危机解决、深度服务类的工作，而不是流水线式的简单重复劳动。

11宫(Sc)SAV=31，接近溢出边缘，资源充裕，收入宫底子好。

Moon、Mars、Rahu三颗星都相位11宫（Moon从5宫7th，Mars从4宫7th，Rahu从3宫7th/5th方向）——三颗大星都在看收入宫，这是一个被大量"关注"的宫位：你的社交网络是你的资产，通过关系网络和社交扩展带来的收入机会不少。

| 住客 | Sun(L8)+Mercury(L6/L9)，深度驱动型收入 |

## ——— 12宫（损耗/灵性/海外/隐居）· 射手座 ———

### 【状况概述】

12宫空宫，管家Jupiter（L12，12宫主）去了10宫（事业宫）。12宫主在事业宫——这个配置意味着你的"损耗"往往是通过事业方向流出去的：你在事业上投入大量精力，这是12宫的主要耗散方向。

**12宫(Sg)SAV=17，低于20，触发极端标注：崩塔级别**。这是这张盘里SAV最低的宫位，比任何宫位都低。12宫资源本来就是"损耗"的，SAV极低意味着这里的能量极度匮乏——实际效果可以有两种解读：一是12宫的"成本"很低（你的损耗和无形消耗比一般人少），二是12宫的"回报"也低（灵性修行、海外发展、隐居式创作等方向，先天资源不够充裕）。

结合Jupiter管12宫且落10宫：木星把12宫的能量引到了事业方向，SAV=17意味着这种引流是"把少量资源全部导向事业"，不会有太多留存在12宫本身。

12宫无行星相位（相位表显示8宫和12宫均无行星投射），这个宫位相当清净，不是这张盘的活跃区域。

| 维度 | 结果 |
|------|------|
| 管家 | Jupiter(L12,[欺骗性风险])→10宫，损耗流向事业 |
| 住客 | 空宫 |
| 相位 | 无 |
| 宫位SAV | **12宫(Sg)=17，崩塔**，12宫本身资源极匮乏 |
